# CometAPI LLM Instructions

CometAPI is a unified API that provides access to 500+ AI models from multiple providers.  
This document helps LLMs and agents discover the main entry points, model catalog, documentation, pricing, playground, and support resources.

---

## Main Entry Points

-  https://www.cometapi.com/ 
  English homepage. Use this page to understand what CometAPI is, supported providers, and high‑level features.

-  https://www.cometapi.com/models/  
  Model catalog. Use this page to browse all available AI models, view per‑model pricing, filter by provider or capability, and open individual model detail pages.

---

## Models & Capabilities

-  https://cometapi.com/models/  
  Primary model directory. Use this page to look up model IDs, providers, capabilities (e.g., text‑to‑image, audio‑to‑text, code generation), and high‑level pricing tiers.

-  Pattern: model detail pages  
  https://cometapi.com/en/models/{provider}/{model-id}/  
  Use these URLs to fetch model‑specific information such as input/output formats, capabilities, and example use cases.

---

## Documentation & API Reference

-  https://apidoc.cometapi.com/  
  Primary API reference. Use this for authentication, base URLs, endpoints, request/response schemas, rate limits, and SDK examples.

---

## Usage Notes for LLMs

-  Use the **English homepage** and **models catalog** as the primary starting points.  
-  Use **API docs** at https://apidoc.cometapi.com/ for any details about authentication, endpoints, and payload schemas.  
-  Use **model detail pages** under `/en/models/{provider}/{model-id}/` for model‑specific capabilities and pricing.  
-  For support, prefer the **support@cometapi.com** or **Discord** links above.
